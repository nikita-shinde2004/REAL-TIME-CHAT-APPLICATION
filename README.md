💬 Real-Time Chat Application

The Real-Time Chat Application is a web-based project developed as Task-2 of the CODTECH Internship Program. This application is designed to enable instant communication between multiple users through a real-time messaging system. It focuses on implementing live data exchange and client–server interaction using modern web technologies, providing users with a smooth and responsive chatting experience.

The application is developed using Node.js, Socket.IO, HTML, CSS, and JavaScript. Node.js is used to create the backend server responsible for handling user connections and broadcasting messages. Socket.IO enables real-time, bidirectional communication between the server and connected clients. The frontend is built using HTML and CSS to provide a clean and user-friendly chat interface, while JavaScript manages client-side logic and socket events.

Users can open the application in multiple browser tabs or devices and communicate with each other instantly. When a message is sent by one user, it is transmitted to the server and immediately delivered to all connected users without requiring a page refresh. This real-time message flow makes the application efficient and closely similar to real-world chat systems.

The project emphasizes event-driven programming, WebSocket communication, and asynchronous behavior, helping users understand how real-time applications function internally. The application was developed using Visual Studio Code (VS Code), which provided an efficient environment for writing, testing, and debugging both client-side and server-side code.

🚀 Features

Real-time messaging between multiple users

Instant message delivery without page reload

Multiple users can join the chat simultaneously

Event-driven communication using Socket.IO

Simple, clean, and user-friendly chat interface

Responsive design for different screen sizes

Efficient client–server communication

🛠️ Technologies Used

HTML – Structure of the chat interface

CSS – Styling and responsive layout

JavaScript – Client-side logic and socket event handling

Node.js – Backend server and connection management

Socket.IO – Real-time, bidirectional communication

Visual Studio Code (VS Code) – Development environment
